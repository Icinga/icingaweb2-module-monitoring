# Installing Monitoring Module from Source

Please see the Icinga Web documentation on
[how to install modules](https://icinga.com/docs/icinga-web-2/latest/doc/08-Modules/#installation) from source.
Make sure you use `monitoring` as the module name. The following requirements must also be met.

### Requirements
* [Icinga Web 2](https://www.icinga.com/products/icinga-web-2/) ≥2.13
* PHP version ≥7.2 and ≤8.3
