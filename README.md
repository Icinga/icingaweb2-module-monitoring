# Monitoring module for Icinga Web 2
> **Deprecated:** This module only receives security fixes.
> The recommended successor is [Icinga DB Web](https://icinga.com/docs/icinga-db-web).

The monitoring module provides an intuitive user interface for monitoring with Icinga 2.
There are lots of list and detail views (e.g. for hosts and services)
you can sort and filter depending on what you want to see.

You can also control the monitoring process itself by sending external commands to Icinga.
Most such actions (like rescheduling a check) can be done with just a single click in the UI.

## Requirements
* [Icinga Web 2](https://www.icinga.com/products/icinga-web-2/) ≥2.13
* PHP version ≥7.2 and ≤8.3
